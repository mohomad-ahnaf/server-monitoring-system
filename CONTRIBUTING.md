# Contributing to Server Monitoring System

Thank you for your interest in contributing! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/server-monitoring-system.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit: `git commit -m "Add your feature"`
6. Push: `git push origin feature/your-feature-name`
7. Create a Pull Request

## Code Style

- Python: Follow PEP 8
- JavaScript: Use consistent indentation (2 spaces)
- HTML/CSS: Use semantic HTML and BEM for CSS classes
- Bash: Use shellcheck for validation

## Commit Messages

Use clear, descriptive commit messages:
```
- feat: Add new feature
- fix: Fix bug
- docs: Update documentation
- style: Format code
- refactor: Restructure code
- test: Add tests
```

## Testing

- Test locally before pushing
- Ensure Flask app starts correctly
- Check database operations
- Verify Docker builds and runs

## Pull Request Guidelines

- Include descriptive title and description
- Reference any related issues
- Ensure code follows project style
- Add documentation for new features
- Test in Docker environment

## Reporting Issues

Please include:
- Clear description of the issue
- Steps to reproduce
- Expected vs actual behavior
- Your environment (OS, Python version, etc.)
- Logs and error messages
